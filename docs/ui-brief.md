## アプリの概要

知り合いの農家から 30kg 単位で米を買っている家庭の、**米の受取記録アプリ**。使うのは本人 1 人で、iPhone のホーム画面に追加して使う（PWA）。開くのは「米を受け取った日」と「そろそろ次を頼むか考える日」くらいで、**月に数回、数秒だけ開く**使い方。

- 一番知りたいこと: **次にいつ頼めばよいか**、**前回からもう何日経ったか**
- 次に知りたいこと: これまでに何 kg 買ったか、代金の払い忘れが無いか
- 言語: 日本語のみ。単位は kg・円・日

## 画面と中身

### 1. ホーム

上から重要な順:

| 要素 | 例 | 備考 |
|---|---|---|
| 次回購入の予測日 | 「次の目安 10月29日（あと 28 日）」 | 主役。予測日を過ぎたら「目安を 3 日過ぎています」。予測できないときは理由（「予測には 2 回以上の記録が必要です」） |
| 前回の受取からの経過日数 | 「前回 9月20日から 11 日」 | |
| 累計購入量 | 「これまで 240 kg（8 回）」 | |
| 未払い | 「未払い 1 件 13,000 円」 | 0 件なら出さないか控えめに |
| バックアップ状態 | 保存済み／保存待ち／未設定／エラー | 小さく。エラー時だけ目立たせる（例「GitHub の鍵を設定し直してください」） |
| 「受け取った」ボタン | | 記録の追加への入口。片手の親指で押せる位置 |

### 2. 記録の追加・編集（シートまたは画面）

| 項目 | 既定値 | 入力 |
|---|---|---|
| 受取日 | 今日 | 日付。未来日は選べない |
| 量 | 前回の値（初回は 30） | kg、小数 1 桁まで。30 がほとんどなので素早く確定できるとよい |
| 代金 | 空 | 円・任意 |
| 支払い済み | 未払い | オン／オフ |

- 下に「保存」。編集時は「削除」も（確認つき）
- 保存に失敗したら入力を残したままエラーを出す

### 3. 記録一覧

- 受取日の新しい順。1 行に: 受取日・kg・代金・kg 単価（代金があるときだけ）・支払い状況
- 行を押すと編集へ

### 4. 集計

- 年ごとの kg と代金の合計（表）
- 月別の kg（棒グラフ）
- 購入間隔の推移（何日おきに買っているか）

### 5. 設定

- GitHub バックアップ: 保存先（ユーザー名・リポジトリ名）、鍵（トークン）の入力、状態、「今すぐ保存」
- 復元: 「GitHub から復元」「JSON ファイルから復元」「復元の取り消し」（取り消しは直前に復元したときだけ）
- 「JSON ファイルに書き出し」
- 「次回の目安をカレンダーに登録」（予測日の 3 日前に通知が出る予定を iPhone のカレンダーへ追加）
- アプリのバージョン

### 6. 確認・警告のダイアログ

- 復元の確認: 「端末の 8 件（240 kg・最終 9月20日）を、バックアップの 8 件（240 kg・最終 9月20日）で置き換えます」の比較表示＋「置き換える」「やめる」
- 衝突: 「GitHub 側に、この端末が送っていないデータがあります」＋両者の比較＋「端末の内容で上書き」「GitHub から復元」
- ホーム画面に追加していないとき（Safari で開いているとき）の案内: 「ホーム画面に追加して使ってください」
- アプリ更新が必要なとき: 「新しい版のアプリで作られたデータです。アプリを更新してください」

## 状態違いで見たいもの

1. 記録 0 件（初回起動。何をすればよいか分かる空の状態）

## 守ってほしいこと

- iPhone のホーム画面アプリとして使う前提（上下のセーフエリア、Dynamic Island を避ける）
- タップ領域は 44pt 以上
- 外部のフォント・画像・スクリプトを読み込まない（セキュリティ上、アプリは自分のサイトと GitHub 以外に通信しない。フォントは端末のシステムフォント）
- ライト／ダークの両方

## 採用したデザインと、画面の実装（U3）で確かめること

- 採用: 「残り日数のポスター」案（2026-10-01 ユーザー採用）。キャンバス https://claude.ai/artifact/L9pk8iDAsVbFKY9DwpxKDi （非公開）。判断は Vault `Decisions/2026-10-01-kome-app-UIの方向性.md`
- アイコン: 実物の 30kg クラフト米袋を 2 袋積んだ C 案（`assets/icon/icon-master-1024.png`、書き出しは `public/icons/`）
- Codex の意見（2026-10-01）から、U3 で確かめること:
  - 予測日の当日は「今日が目安」と出す（「あと 0 日」にしない）
  - バックアップの状態別の見え方（未設定・保存待ち・network／rate-limit・conflict）をホームと設定に描く
  - 未払いの荷札のタップ領域を 44pt 以上にする
  - 設定で、復元などデータを置き換える操作を他の項目と分けた群にする
  - 文字サイズを最大にしたとき（Dynamic Type 相当）の折り返しを確かめる
